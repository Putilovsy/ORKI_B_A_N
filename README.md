# Gotham: After Dark — Скролл-шутер (Java + LibGDX)

Базовая структура проекта и тестовый прототип в соответствии со стандартами LibGDX.

---

## 📁 Структура проекта

```text
Game/
├── assets/                          # Игровые ресурсы
│   ├── textures/                    # Текстуры и спрайты (.png)
│   ├── sounds/                      # Звуковые эффекты (.wav, .ogg)
│   ├── music/                       # Фоновая музыка (.mp3, .ogg)
│   └── fonts/                       # Шрифты (.fnt, .ttf)
├── core/                            # Кроссплатформенная игровая логика
│   ├── build.gradle                 # Зависимости основного модуля
│   └── src/main/java/ru/orki/game/
│       ├── MainGame.java            # Главный тестовый класс (прототип движения)
│       ├── screens/                 # Будущие экраны (меню, игра, геймовер)
│       ├── entities/                # Игровые объекты (игрок, враги, пули, препятствия)
│       ├── systems/                 # Системы и менеджеры (спавн, коллизии, ввод, очки)
│       └── utils/                   # Константы, настройки, вспомогательные утилиты
├── lwjgl3/                          # Модуль запуска игры для десктопа (ПК)
│   ├── build.gradle                 # Зависимости десктопного бэкенда (LWJGL3)
│   └── src/main/java/ru/orki/game/lwjgl3/
│       └── DesktopLauncher.java     # Точка входа (main метод с конфигурацией окна)
├── gradle/wrapper/                  # Gradle Wrapper для сборки без предустановленного Gradle
├── build.gradle                     # Корневой скрипт сборки Gradle
├── settings.gradle                  # Подключение подпроектов core и lwjgl3
└── gradle.properties                # Настройки JVM и сборщика
```

## 🎮 Экраны и управление

### 1. Главное меню (`MainMenuScreen`)
- **Кнопка PLAY (Играть):** переход на экран геймплея.
  - Активация: клик левой кнопкой мыши или клавиши `Enter` / `Пробел` / цифра `1`.
- **Кнопка EXIT (Выход):** закрытие приложения.
  - Активация: клик левой кнопкой мыши или клавиши `Esc` / цифра `2`.
- Интерактивность: кнопки подсвечиваются при наведении курсора мыши.

### 2. Тест геймплея (`GameScreen`)
- **Движение:** клавиши `A` / `D` или стрелки `←` / `→` для перемещения влево и вправо.
- **Ограниченное пространство:** позиция квадрата ограничена пределами дорожного полотна (`MathUtils.clamp`).
- **Выход в меню:** нажатие клавиши **`Esc`** моментально возвращает игрока в главное меню.

## 🚀 Как запустить

### 1. Требования
- Установленный **JDK 17** (или выше).

### 2. Запуск через IntelliJ IDEA (рекомендуется)
1. Откройте папку `Game` через **File -> Open**.
2. Дождитесь, пока IntelliJ IDEA автоматически распознает и синхронизирует проект Gradle.
3. Откройте файл `lwjgl3/src/main/java/ru/orki/game/lwjgl3/DesktopLauncher.java` и нажмите зеленую стрелку запуска рядом с методом `main`.

### 3. Запуск из терминала
В папке проекта выполните:
```powershell
.\gradlew.bat lwjgl3:run
```
*(на Linux/macOS: `./gradlew lwjgl3:run`)*
